# C4 architecture views

These Mermaid diagrams apply C4's four useful levels to the as-built system.
They are intentionally small enough to stay synchronized with source. Mermaid
is the canonical editable format; rendered images, if added, are derivatives.

1. [`01-system-context.md`](01-system-context.md)
2. [`02-containers.md`](02-containers.md)
3. [`03-components.md`](03-components.md)
4. [`04-deployment.md`](04-deployment.md)

The diagrams describe the current modular monolith. Proposed multi-location,
outbox, or external identity components belong in RFC diagrams until accepted.
