# Security policy

StockVerity is a portfolio system under active hardening, not a production
service or certified inventory platform. Supported-version and disclosure
instructions are maintained in [`docs/SECURITY.md`](docs/SECURITY.md).

Please do not publish secrets or working exploit details in a public issue.
Use the repository Security tab's private
[vulnerability-reporting form](https://github.com/AbubakarMahmood/ASP.NET-Core-Inventory-Management-API/security/advisories/new).
